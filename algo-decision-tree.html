Decision Tree

"Will this order be late?"

In plain words

It predicts whether a delivery will be late by asking a short list of yes-or-no questions.

Think of it like this: A checklist a dispatcher might use. Is the courier a slow one? Is the distance long? Each answer leads to the next question, until there is a final answer.

Try the demo

  1. Choose the product type, courier, seller rating, and distance.
  2. Read the result and the percentage shown.
  3. Use the path to see which answers led to the result.

Words to know

Late delivery
A delivery that arrives after the promised date.
Seller rating
How customers have rated the seller, from 1 to 5.
Chance
An estimate based on past deliveries. It is not a certainty.

What it is

A Decision Tree works like a flowchart of yes/no questions, for example "Is the seller rating below 3.5? Is the shipping distance long?", ending in an answer such as "likely late."

Why Allonola uses it

Late deliveries and returns damage buyer trust and cost sellers money. The Decision Tree powers the return and late-delivery warnings in the admin dashboard and the courier performance views. It provides transparent, rule-based predictions that staff can easily audit and act upon.

How it works

The tree repeatedly splits the data on the input that best separates the outcomes, measured by Gini impurity or information gain. Each branch is a rule and each end point (leaf) is a prediction. Its main strength is that staff can trace exactly why an order was flagged.
